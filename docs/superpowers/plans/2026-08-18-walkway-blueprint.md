# Walkway Blueprint Pass — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the perimeter walkway from arrangement-schematic to a fabricator-ready blueprint package — geometry corrected, dimensions parametric, structurally validated (US IBC/OSHA), with fastener/weld/datum schedules and fab-detail sheets — mirroring the IBC-frame and film-plane-corner blueprint standard.

**Architecture:** Phased single pass on branch `walkway-bp`. **Phase 0** resolves four real geometry fixes in the SketchUp generators FIRST (models regenerate → `--send` → ALVIN saves/uploads), gated on `check_interference.py --solids` clean. **Phase 1** promotes model-local `RWK_*` constants into `tbs_constants.py` and adds the un-parametrized blueprint dimensions. **Phase A** adds `walkway_load.py` (analog of `ibc_frame_load.py`). **Phases B–D** add the fastener/weld/datum schedules and fab-detail sheets to `generate_walkway_diagram.py`. **Phase E** cascades to parts/costing/BOM and closes.

**Tech Stack:** Python 3 (matplotlib diagrams), SketchUp Ruby (generated by `src/models/*.py`, pushed via the `--send` MCP client), and the repo's own tooling: `lint.py`, `check_consistency.py`, `check_interference.py`, `manifest.py`, `facts.py`/`costing.py`/`parts.py` injectors.

## Global Constraints

Copied verbatim from `walkway-blueprint-spec.md` and `CLAUDE.md`. Every task implicitly includes these.

- **Models are generated from code only.** Never hand-edit live `.skp` geometry to "fix" a position. `eval_ruby` is READ-ONLY (inspection/verification). Edit generator → regenerate → `--send`.
- **`--send` ONLY into the matching open doc.** Before any `--send`, query `Sketchup.active_model.title` via `eval_ruby`; if it matches → send (safe rebuild of same model into its own doc); if it does NOT match → do NOT send, ASK Alvin to open the right model and wait.
- **ALVIN is the sole `.skp` saver.** After a clean `--send` + read-only verify, tell Alvin "clean — save + upload"; he does File>Save + re-uploads to Sketchfab (same UID). **Commit the `.skp` only AFTER he confirms "saved + uploaded."**
- **Re-send order = focus-model-first:** `walkway.skp` before `overview`/`construction`/`water` (Alvin validates the focus model first).
- **Drive every regen/re-send from `python3 src/generators/lint.py --cascade <CONST>`** — the authoritative import-graph list — never from grep or memory. Run `lint.py --verify-all` before publish.
- **Regenerate `.rb` with `/usr/bin/python3`** (not bare `python3`) — float noise trips `verify-all` as STALE.
- **`.rb` are NOT committed** (gitignored build artifacts); their `dependencies.yml` `source_hash` is the tripwire. Run `manifest.py --update` after a legitimate re-send and commit the updated `.skp` + `dependencies.yml`.
- **Single source of truth:** every recurring value has ONE home (`tbs_constants.py` geometry / `parts.py` procurement / `costing.py` money / `facts.yml` prose aliases). Placeholder-first (`<!-- BEGIN fact:KEY -->…`). Derive, don't hardcode. **Reference constants in generator label strings** (`f"{RWK_BEARER_W}"`, not `"50.8"`).
- **License header (SPDX AGPL-3.0-only + © 2026 Alvin Richards)** on every new `.py`/`.md`.
- **New diagram PNG must be registered in ALL of:** `all-diagrams.md` gallery, `publish.sh` (`DIAG_FILES`), `setup_docs.py` (`DIAG_IMAGE_FILES`), `dependencies.yml`.
- **Any spec change updates `parts.py`/`costing.py`/master-shopping-list/cost-breakdown in the SAME commit.** Gated by `parts.py --check` + `costing.py --check-registry`.
- **American English spelling.** All source refs hyperlinked. Plywood = standard exterior (not marine) for dry/backing use.
- **Add a `RELEASE.md` `[Unreleased]` bullet as notable work lands** (same work, not later).
- **Git:** never `git add -A`/globs — type explicit paths. No `Co-Authored-By` line. Commit automatically; deploy only on request or after a merge.
- **Load basis = US IBC/OSHA:** 60 psf (2.87 kPa) uniform + 300 lbf (1.33 kN) concentrated.
- **Cantilever ownership:** the two center arms on the IBC uprights + their J6 connection are IBC-frame-owned — cross-reference, do NOT dimension/validate/cost them here.
